## 📖 Descripción del Proyecto

**"Gestión del Cambio"** es un simulador educativo diseñado para poner a prueba las habilidades de toma de decisiones en contextos de transformación organizacional.

El caso de estudio "Transformación Digital en TecnoSoluciones" guía al usuario a través de **5 decisiones clave** que determinarán el éxito o fracaso de un proceso de cambio.

Cada decisión tiene:
- ✅ **Contexto** de la situación actual.
- ✅ **3 opciones** de respuesta (1 correcta, 2 incorrectas).
- ✅ **Retroalimentación inmediata** con explicación detallada.
- ✅ **Puntaje** para evaluar el desempeño.

## 🚀 Características

| Característica | Descripción |
|---|---|
| 🔐 **Autenticación** | Registro e inicio de sesión con Firebase Authentication |
| 📊 **Base de datos** | Firestore para almacenar preguntas, respuestas y usuarios |
| 📝 **Preguntas interactivas** | Contexto, opciones y retroalimentación inmediata |
| 🏆 **Sistema de puntaje** | 20 puntos por respuesta correcta (100 puntos máximo) |
| 📈 **Barra de progreso** | Visualización del avance en el simulador |
| 📋 **Resultados finales** | Resumen de respuestas y mensaje personalizado |
| 📱 **Responsive** | Adaptado para móviles, tablets y escritorio |
| 🔒 **Seguridad** | API Key restringida por dominio y APIs específicas |
